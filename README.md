# Guia de Aventura — Ionic Vue + TypeScript

Aplicativo mobile construído com Ionic Vue 3, TypeScript, Capacitor e Leaflet/OpenStreetMap.

## Executar

```bash
npm install
npm run dev
```

Em dispositivo físico, use uma URL HTTPS para permitir geolocalização e sensores.

## Recursos

- Permissão de geolocalização e atualização contínua da posição.
- Mapa com posição do usuário e três pontos turísticos.
- Bússola com N, S, L e O usando o sensor de orientação.
- Distância calculada por coordenadas, detalhes, imagens e rota no Google Maps.
- Filtro “Perto de mim” em um raio de 5 km.
